# 90초 데모 스크립트

배포 URL: https://boardroom-six-delta.vercel.app
백업 공유: https://boardroom-six-delta.vercel.app/s/w4demo

총 90초. 결정은 사람이 한다는 문장을 반복한다.

| 초 | 화면 | 말할 것 |
|---|---|---|
| 0–10 | `/` | "세 회사의 모델이 서로 다른 입장을 내고, 결정은 사람이 합니다." |
| 10–25 | 안건 입력 | 준비 안건 "백내장 검색광고 예산 30% 증액". 실토론 준비됨이면 **토론 시작**. 키가 없으면 **데모 재생**. |
| 25–50 | 그리드 | 셀 단위 로딩. R1 세 입장(현금흐름 / 선점 / 부하)이 갈라지는 지점만 가리킨다. |
| 50–70 | R2 | objection·changed. 모델이 합의하지 않았다는 점을 강조. |
| 70–85 | 메모 | 실토론이면 네 칸을 채운 뒤 저장. 데모 재생이면 이미 채워진 사회자 메모를 가리킨다. |
| 85–90 | `/s/[id]` 또는 `/s/w4demo` | 로그인 없이 같은 내용. |

실호출이 실패하면 주저하지 말고 홈의 **데모 재생** 또는 백업 링크로 넘어간다. 심사 가치는 "결정 대신"이 아니라 "대립 표면화"다.
