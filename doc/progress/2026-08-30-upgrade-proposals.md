# 2026-08-30 Planner: 기능 고도화 제안

지금은 MVP(F1–F6) + 업로드·데이터 검토·한글 순화가 배포되어 있다. 가치는 그대로다. **결정을 대신하지 않는다. 반대·가정·필요 데이터를 올린다.**

새 메뉴·4번째 LLM·라운드 3·자동 합의 초안·인증은 하지 않는다.

## 지금 비는 곳

| 이미 있는 것 | 아직 약한 것 |
|---|---|
| 12개월 표(수술·현금) | 올린 환자더미의 유입·국적·성별·나이·지역은 표에 안 나옴 |
| 6칸 발언에 위험·필요 데이터 | 사회자 메모는 빈 칸부터. 90초 데모에서 타이핑이 길다 |
| 유형 드롭다운 | 태그만. 토론 프롬프트에는 안 들어감 (의도) |
| 공유 `/s/[id]` | 심사·병원장에게 한 장으로 보여 주기 약함 |

## 하지 말 것

- 라운드 3, 자동 합의문, 제공사 변경 UI, 사이드바 7칸
- 인사이트 전용 모델 (데이터 검토가 이미 3인 토론)
- 원본 환자 파일을 서버에 저장

---

## 패키지 (작은 순)

### P1. 쟁점 모음 — 추천, LLM 0

토론 결과·의사결정 위에, 이미 나온 JSON만 모아 보여 준다.

- 세 반대 문장
- 필요 데이터 합집합 (중복 제거)
- 위험 합집합

사회자 메모의 「부족한 데이터」만 이 목록으로 **채워 두고**, 합의점·선택지는 비워 둔다. 합의를 쓰지 않으므로 PRD의 자동 메모 제외와 충돌하지 않는다.

성공: 데모 세션 `w4demo`에서 필요 데이터가 3개 이상 보이고, 합의 칸은 비어 있다. HTTPS. 토론 시작 클릭 없음.

### P2. 업로드 통계를 환자더미와 맞추기 — LLM 0

`/files` 표에 이미 파싱된 값을 칸만 더한다.

- 검색광고 / 소셜 / 소개 / 해외 유입
- 국내·중국·일본 비중 (마지막 월 또는 기간 평균)
- 인구통계가 있으면 성별·나이대·지역 한 줄

성공: `hospital-patients-full.xlsx` 업로드 후 표에 유입 또는 인구통계가 보인다. LLM 0.

### P3. 이상월 칩 — LLM 0, 프롬프트는 선택

코드로 순현금·검색광고 유입·의사 1인당 수술의 최고·최저 월을 계산해 `/files`에 칩으로 붙인다. 데이터 검토 시에만 표 위에 두 줄 요약을 얹으면 모델이 영문 키 대신 그 월을 인용하기 쉽다.

성공: 더미 CSV에서 순현금 최고 월이 칩으로 보인다. 실토론 클릭 없음.

### P4. 심사 90초 — 안건만 넣고 시작은 사람이

홈에 「심사 안건」. 누르면 `백내장 검색광고 예산 30% 증액`만 채운다. 토론 시작은 누르지 않는다. 장애 시 `/s/w4demo`는 이미 있다.

성공: 버튼 후 안건 칸이 10자 이상. E2E는 토론 시작을 누르지 않음.

### P5. 공유 한 장

`/s/[id]`에 링크 복사, 인쇄용 스타일(배경 회의실 생략). 심사·병원장 전달용.

성공: 공유 페이지에 「링크 복사」. HTTPS.

## 고르면 좋은 순서

대회(9/21)가 우선이면 **P1 → P4 → P5**.  
올린 엑셀을 더 쓰려면 **P2 → P3 → P1**.

한 번에 하나만 지정한다. Planner가 칸을 나눈 뒤 Executor가 실행한다.
