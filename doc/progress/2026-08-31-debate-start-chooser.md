# 2026-08-31 토론 시작 선택

사용자가 안건 옆 「토론 시작」이 없다고 했다. 헤더 「시뮬레이션 다음 턴」만 있고, 누르면 올린 파일이 있으면 무조건 넣었다.

## 한 일

- 왼쪽 안건·유형 아래에 보이는 「토론 시작」(`aria-label="토론 시작"`).
- 헤더 「시뮬레이션 다음 턴」은 시안 유지. accessible name은 `시뮬레이션 다음 턴` (같은 이름을 두 개 두면 E2E boundingBox가 깨짐).
- 둘 다 바로 LLM을 부르지 않는다. 선택 창: **올린 데이터로 진행** / **그냥 진행** / 취소.
- 올린 파일이 없으면 첫 칸은 disabled. 그냥 진행은 `metrics` 없이 POST → 서버가 기본 합성 지표를 씀.
- 「데이터 검토」는 기존처럼 올린 지표 + 고정 안건. 선택 창 없음.
- 단위: `debateStartBody`. E2E는 선택 창·취소만. 「올린 데이터로 진행」「그냥 진행」「데이터 검토」실클릭 없음.

## 검증

- 로컬 단위 테스트. 선택 창 열림·취소는 브라우저에서 확인.
- HTTPS E2E는 배포 후.
