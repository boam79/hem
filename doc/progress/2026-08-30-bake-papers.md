# 2026-08-30 서류를 회의실에 구워 넣음

## 10단계

1. 바인더가 맞는 이유: `forest-room.png`에 같이 그려져 조명·원근·점토가 같다.
2. 중앙 서류가 안 맞는 이유: 다른 PNG를 올려 스티커가 된다.
3. 필터·세피아·크기 조절은 스티커를 남긴다.
4. 대기·토론 후도 같은 회의실 카메라여야 한다.
5. 대기는 `forest-room-idle.png` — 짧은 서류산이 빈 나무에 앉아 있다.
6. 업로드·토론은 `forest-room-stacked.png` — 같은 산을 조금 높게.
7. 크기는 바인더와 비슷하게. UI 타워가 아니다.
8. CSS 흰 글로우·별도 종이 PNG 오버레이는 끈다. 스파클만 쌓인 뒤에.
9. 「자료를 올려 주세요.」는 대기만. 말풍선은 테이블에 없음.
10. HTTPS에서 대기 홈과 업로드 후 홈을 확인한다.

## 이번에 한 일

- 실토론 버튼은 누르지 않는다.
