# 2026-08-30 Planner: 데이터 검토 회의 + 업로드 통계

메뉴는 **늘리지 않는다.** 둘 다 기존 화면에 붙인다.

| 원하는 것 | 위치 | LLM |
|---|---|---|
| 올린 숫자 통계 | `/files` 파일 관리 | 없음 |
| 안건 없이 데이터 회의 | 홈 `/` 보조 버튼 | 있음 (기존 3인 토론) |

사이드바는 그대로: 홈 · 토론 결과 · 대시보드 · 파일 관리 · 의사결정 · 설정.

인사이트는 따로 모델을 부르지 않는다. 데이터 검토 회의의 3인 발언이 인사이트다.

## 하지 않는 것

- 새 메뉴 `/stats`, `/insights`
- 대시보드에 지표 표 넣기 (대시보드는 연결·최근 회의)
- 안건 10자 규칙 삭제 (서버 계약 유지)
- E2E에서 「데이터 검토」 클릭 (실 LLM 비용)

## 1. 통계 — 파일 관리

업로드가 성공하면 같은 페이지에:

- 병원명, 기간, 의사 수
- 12개월 표 (라식·스마일·ICL·백내장, 현금)
- 합계 몇 칸 (수술 합, 기간 순현금)

숫자는 브라우저에 저장된 마지막 파싱만. 새 API 없음. 기본 `S안과` 합성 지표는 여기서 보여 주지 않음 (올린 파일만).

성공: 더미 CSV 업로드 후 파일 관리에 `업로드안과(가상)`과 월 열이 보인다. LLM 호출 0.

## 2. 데이터 검토 회의 — 홈

안건 칸은 비워 둬도 된다. 큰 버튼 「토론 시작」은 지금처럼 안건 10자 필요.

그 아래(또는 옆) 보조 버튼 **「데이터 검토」**:

- 업로드가 없으면 비활성. 안내: 파일 관리에서 올리세요.
- 누르면 서버에는 고정 안건을 넣는다.  
  `업로드한 12개월 지표에서 위험·가정·필요 데이터를 올려라` (10~200자)
- 유형(select)은 화면에 있으면 그대로 보냄. 없으면 `marketing`.
- 이후는 기존 `POST /api/session` + 라운드 스트림과 동일.

성공: 단위 테스트로 고정 안건 길이·업로드 없을 때 버튼 비활성. HTTPS E2E는 버튼이 보이고, 업로드 전에는 disabled. **클릭하지 않음.**
