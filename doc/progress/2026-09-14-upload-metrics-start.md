# 2026-09-14 올린 지표로 토론 시작 · 유형 UI 제거

사용자가 병원 지표를 올린 뒤 「토론 시작」을 눌러도 그 숫자가 발언에 안 들어간다고 했다. 유형(마케팅·인력·가격) 드롭다운은 쓸모가 없어 보였다.

## 원인

- 「토론 시작」은 선택 창만 열었다. 「그냥 진행」은 올린 파일을 빼고 기본 합성 지표 `S안과(가상)`만 넣는다. 화면에는 올린 병원명이 남아 있어서 파일이 들어간 것처럼 보인다.
- `sessions.category`는 DB CHECK용 태그다. 페르소나 프롬프트·가중치에는 한 번도 안 들어간다.

## 한 일

- 올린 지표가 있으면 「토론 시작」이 바로 그 파일을 넣는다 (`useUploadedMetrics: true`). 파일이 없을 때만 선택 창(기본 합성 지표 / 취소).
- 홈에서 유형 드롭다운을 지웠다. POST `category`는 `marketing` 고정.
- 라운드 프롬프트에 `[지표 출처] 사용자가 올린 파일입니다. 병원: …` 줄을 넣었다.
- 홈에 `토론 시작 시 올린 지표를 넣습니다` 힌트. 홈 말풍선은 한 줄 입장이라 숫자는 회의록 근거에 있다.

## 검증

- 단위: `debateStartBody` · `shouldStartWithUploadedMetrics` · 프롬프트 출처 줄.
- E2E: 업로드 후 힌트만 확인. 「토론 시작」「그냥 진행」「올린 데이터로 진행」「데이터 검토」실클릭 없음(실 LLM). 파일 없을 때 선택 창·취소는 유지.
- HTTPS 실토론은 배포 후. 사용자가 「토론 시작」한 번으로 확인.

## 하지 않은 것

- 유형을 프롬프트 가중치로 넣는 일.
- 커밋·푸시(요청 없음).
