# 2026-08-30 Executor: 토론 결과 한글·순화

저장된 회의를 다시 돌리지 않는다. 화면에서만 영문 지표명·약어를 한글로 바꾼다. 새 토론은 프롬프트 표 헤더가 한글이라 모델이 키를 덜 베낀다.

CSV 업로드 헤더(영문 키)와 JSON 스키마 키는 그대로. 파일 형식은 바꾸지 않음.
