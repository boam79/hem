## 리팩토링 (화면 동일)

### R1. 세션 보기 훅 — 추천, 회귀 낮음

회의록·시나리오 결과·인사이트가 같은 `queryId || 최근 id` → 데모 JSON 또는 `GET /api/session`을 복제한다.

성공: 세 페이지가 `useSessionView`만 쓰고, 데모 id·빈 최근 목록 단위 테스트. HTTPS E2E는 페이지 문구만. LLM 없음.

### R2. 홈 토론 훅 — 대회 후

`page.tsx`에서 start/leave/stream 상태를 훅으로 뺀다. 레이아웃 CSS는 건드리지 않는다.

성공: 홈 JSX는 입력·장면·선택 창만. `leaveMeeting`은 세션만 비우고 안건·파일은 남긴다(기존과 같음).

### R3. CSS 분리 — 대회 후, 위험 높음

홈 규칙만 `home.css`로 옮긴다. 목표 줄 수 절반은 아님. `100dvh` 회귀가 있으면 즉시 되돌린다.

### R4. E2E `합의점` 중복 — 싸고 지금

의사결정 페이지 스모크가 같은 글자 두 곳에 걸려 strict 실패한다. `getByRole` 또는 `exact`로 고친다.

성공: 해당 테스트 초록. 실 LLM 버튼 클릭 없음.

### R5. 죽은 선택자 — 대회 후

지운 도크·장면 위 「회의 나가기」 CSS를 검색해 0으로 만든다. 화면 동일.

## 신뢰 (실 LLM 포함)

홈 6셀·데이터 검토·평가 스크립트는 계속 실제 3사 호출이다. Playwright 기본 스모크는 실클릭을 피하고, **검증은 HTTPS 실토론으로 한다.**

### H1. Haiku 라운드 2 빈 objection — 대회 전, 빼지 않음

5안건 중 4에서 재발한 기록이 있다. 공유 페이지만 쓰고 실토론을 빼지 않는다.

성공: 동일 안건 3회 HTTPS에서 R2 okCount=3. 진행 클릭은 평가 스크립트(또는 사람 한 번).

### H2. 실패한 셀만 다시 호출 — 선택, 같은 3사

라운드 후 `failed` 셀에 「다시」. 새 모델 없음.

성공: 실패 1셀만 POST. 단위 테스트로 대상 페르소나 1명. HTTPS는 실패가 있을 때만.
