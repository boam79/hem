# W3 평가 프로토콜

실모델 키가 Vercel·로컬에 연결된 뒤에만 실행한다. 결과는 이 파일을 복사해 `doc/progress/YYYY-MM-DD-w3-eval.md`에 숫자로 남긴다. E2E는 배포 HTTPS만 사용한다.

## 안건 5종

1. 투자: "스마일 전용 레이저 리스 계약 12개월"
2. 마케팅: "백내장 검색광고 예산 30% 증액"
3. 인력: "상담 간호사 1명 충원으로 설명 시간 확보"
4. 가격: "ICL 패키지 가격 8% 인하"
5. 해외환자: "중국 에이전시 수수료 구간 상향"

## 반복

각 안건을 배포 URL에서 10회. 기록 열:

| 회차 | 안건 | R1 성공 셀 | R2 objection 충족 | 셀 실패 | R1 지연 ms | 비고 |
|---|---|---|---|---|---|---|

## 통과 기준 (PRD §15)

- 라운드 2 성공 셀의 `objection` 공란 없음
- 셀 실패는 허용하되, 같은 페르소나가 연속 3회 실패하면 모델 ID 교체 후보를 적는다
- 페르소나 붕괴: 3셀 position이 같은 결론이면 횟수를 센다. 3회 이상이면 온도·프롬프트 조정

## 실패 처리 확인

- 한 셀 실패 시 나머지 셀은 그대로 보이고 "발언 불가"가 남는지
- R1 성공 < 2이면 R2가 422인지
- 같은 세션 라운드 재요청 409
- 짧은 안건은 클라이언트에서 버튼 비활성, 서버는 400
